# Acca — game shell redesign (v1)

Redesign of Acca's full game shell, generated by **claude.ai/design** on
2026-05-08 and integrated into the live game.

## Files

- `mockup_v1.html` — self-contained interactive mockup as Claude.ai/design produced it
  (omelette runtime stripped so it opens cleanly offline). Use this for
  visual reference; it's not wired into the framework.

## Brief used

- Audience: Acca, a turn-based browser board game (Monopoly + Catan + city-builder
  hybrid, 2–4 hot-seat local multiplayer, Denmark city-development theme).
- Required regions kept intact: 52 px topbar (5 zones — turn / active player /
  cash / net worth / resource pills), left district sidebar, 768×528 canvas
  center, right notifications + player list, modal menu overlay drawn over the
  canvas.
- Visual language: Consolas monospace with `tabular-nums`, dark theme keyed off
  a fixed set of CSS variables (`--bg-deep`, `--panel-bg`, `--accent`, `--gain`
  `#7be07f`, `--loss` `#ff7676`, `--warn`, `--info`, `--hi`, `--glow`), two
  palettes (classic blue / warm orange) toggleable at runtime, faint scanlines
  for retro feel.
- Required CSS hooks preserved (only restyled, not renamed): `.money-gain`,
  `.money-loss`, `.bump`, `.flash-gain`, `.flash-loss`, `.coin-burst`.
- Required DOM ids preserved: `#gameCanvas`, `#tb-turn`, `#tb-name`,
  `#tb-bankrupt-badge`, `#tb-money`, `#tb-networth`, `#tb-resources`,
  `#notifications`, `#playerList`, `#districtList`, `#topbar`, `#gameContainer`,
  `#mapWrap`, `#sidebar`, `#districtSidebar`.
- UX fixes the design addresses:
  1. Game log = scrollable list, not paged; latest entry highlighted.
  2. Property tooltip preview (rent, passive income, owner) before buy
     decision.
  3. Trade menu redesigned with quantity spinners + a visible Confirm button.
  4. "The Man" narrator: pixel-art portrait + speech bubble overlay for chance,
     sabotage, mayor change, and win events.
  5. Unaffordable menu options visibly disabled (dimmed + reason text), never
     silently skipped.
  6. Build vs decorative resources visually grouped.

## What the mockup shows

A populated 4-player board mid-game (turn 23 of 60), Astrid Lindqvist active
as mayor of Nørrebro. Demonstrates: full topbar with grouped build/decor
resource pills, eight-district left sidebar with happiness emojis, a stub
pixel-art canvas, an open Build modal with three affordable + three disabled
options (each disabled option carries a reason: insufficient STN, insufficient
funds, requires Mayor status), a hover preview tooltip pinned to a property
showing rent/passive/yields/buyout, "The Man" delivering a chance event, and a
14-row scrollable game log on the right.

## What landed in the live game

The mockup's design language was ported into the existing CSS layer; no game
logic was changed. The integration is purely visual + structural shell.

Modified:
- `games/Acca/styles/theme.css` — palette tokens (classic + warm), document
  reset, app grid, `#gameContainer` regions, narrator + tweaks panel base.
- `games/Acca/styles/topbar.css` — gradient topbar, `.tb-cell` zones, resource
  pills, money-flash + coin-burst preserved.
- `games/Acca/styles/sidebars.css` — district panel rows, notification rows,
  player rows, money-flash row animations preserved.
- `games/Acca/index.html` — added `data-palette="classic"` on `<html>`, a
  hidden `#acca-narrator` div pinned over the canvas, the bottom-right palette
  toggle, and a tiny inline script that persists the palette choice in
  `localStorage` under `acca.palette`.

Unchanged:
- `games/Acca/ui/HUDRenderer.js`, `games/Acca/ui/MoneyAnimations.js` — class
  names emitted by the HUD (`.res-pill`, `.notif`, `.pl-row`, `.pl-color`,
  `.pl-info`, `.pl-name`, `.pl-stat`, `.dist-row`, `.dist-header`,
  `.dist-name`, `.dist-tag`, `.dist-body`, `.dist-line`, `.dist-mood-*`,
  `.dist-mayor-line`, `.dist-mayor-dot`, `.dim`) all keep working — the new
  CSS targets the same names.
- `games/Acca/AccaGame.js` and the rest of `core/`, `managers/`, `systems/`,
  `render/` — untouched.

## Out of scope for this pass (follow-ups)

The mockup demonstrates these but the live game does not yet wire them:

- Real narrator events: a `showNarrator(text, mood)` hook on `HUDRenderer` and
  call sites in `ChanceSystem` / district mayor changes / win condition.
- Property tooltip preview before a buy decision: needs a hover state on the
  canvas board cells and a DOM tooltip driven from `BoardRenderer`.
- Trade menu rebuild: the `TradeSystem` currently relies on the canvas-drawn
  `Menu` component; the modal-style trade UI in the mockup needs a new
  DOM-driven menu surface.
- Disable-rather-than-silently-skip in `TurnManager` takeover/build menus.
- Surfacing near-miss chance events in the log (`ChanceSystem`).

These are visual-shell-supports-them but require gameplay changes to ship.

## How to view

- The mockup standalone: open `mockup_v1.html` in any browser.
- The live game: serve the repo and open
  `http://localhost:<port>/games/Acca/index.html`. The palette toggle is in
  the bottom-right corner.
