# Framework Sprite Loaders

Each `category.js` file in this directory:
1. Owns the asset path for the spritesheets under `/Sprites/<Category>/<Name>/`.
2. Eagerly loads the spritesheet PNGs via `new Image()`.
3. Registers each sprite under `GF.sprites[<spriteName>]` (or `GF.portraits[]` for portraits).

Built-in characters `claude` and `claudia` have their own dedicated loader files (`claude.js`, `claudia.js`); all other sprites are grouped by category here.
